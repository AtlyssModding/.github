Modding organization centered around maintaining utilities, resources and deprecated mods for [ATLYSS](https://store.steampowered.com/app/2768430/ATLYSS/).

- [How to install mods manually](https://github.com/AtlyssModding/ATLYSS-Modding-Resources/wiki/How-to-install-mods-manually)
- [Resorces for modders](https://github.com/AtlyssModding/ATLYSS-Modding-Resources/wiki/Links#modded-atlyss)
- [Thunderstore page for ATLYSS](https://thunderstore.io/c/atlyss/)
- [ATLYSS Modding Central Discord Server](https://discord.gg/hQceRJ7pEW)
- [Other links and resources](https://github.com/AtlyssModding/ATLYSS-Modding-Resources/wiki/Links)

Mods maintained by the organization:
- [Atlyss UnityExplorer](https://thunderstore.io/c/atlyss/p/AtlyssModding/Atlyss_UnityExplorer/) [(Repository)](https://github.com/AtlyssModding/UnityExplorer), fork of Unity Explorer that works with newer versions of Atlyss
- [AdditionalFastTravel](https://thunderstore.io/c/atlyss/p/AtlyssModding/AdditionalFastTravel/) [(Repository)](https://github.com/AtlyssModding/AdditionalFastTravel/), mod that provides additional fast travel options, originally made by [Clearwater](github.com/ClearwaterUK)
- [AtlyssDedicatedServer](https://thunderstore.io/c/atlyss/p/AtlyssModding/AtlyssDedicatedServer/) [(Repository)](https://github.com/AtlyssModding/AtlyssDedicatedServer), headless server hosting mod originally made by [Fleetime](https://github.com/Flee-Time)
- [ServerPrioritizer](https://thunderstore.io/c/atlyss/p/AtlyssModding/ServerPrioritizer/) [(Repository)](https://github.com/AtlyssModding/ServerPrioritizer), QoL mod for favoriting servers and displaying them first in the server list, originally made by [Fleetime](htps://github.com/Flee-Time)
